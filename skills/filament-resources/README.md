# Filament Resources

Use this skill to create, migrate, or update Filament resources in Laravel applications. See [SKILL.md](SKILL.md) for the agent instructions.

## Example request

```text
Use $filament-resources to create a Product resource with translated names, images, and a category filter.
```

## Project context

Identify the target model and the requested form or table changes. Point to a sibling resource when it demonstrates the conventions to follow.

The skill checks the installed Filament version and existing translation and storage systems. State any requested version or package migration explicitly. Include project-specific labels, tab names, and layout requirements in the project's `AGENTS.md` or your request.
