# worksession

Use this skill to start, inspect, stop, or reconnect to persistent workspace services and interactive terminals through the `worksession` CLI. See [SKILL.md](SKILL.md) for the agent instructions.

## Example requests

```text
Use $worksession to check the status and recent logs of the current project.
```

```text
Use $worksession to start the configured workspace services.
```

For an interactive terminal, ask the agent to attach to a named project from a real local terminal. The skill preserves the same configuration and state directory overrides across related commands.
